# 个人学习与优化

1. 接入并调试百炼 AI 音乐助手，支持多轮对话、曲库工具调用和 SSE 流式回复。
2. 优化用户缓存隔离，避免收藏列表及歌曲、歌单、歌手详情中的收藏状态在不同用户之间混用。
3. 完善邮件验证码功能，优化 SMTP 配置、验证码生成、发送异常处理及注册成功后的验证码清理。
4. 优化收藏歌曲分页查询，本机 2,000 条收藏、8 并发 SQL 查询链路测试，平均耗时由 6.60 ms 降至 3.29 ms。
5. 前置推荐缓存读取，命中时跳过收藏和风格查询，并在收藏变化后清理对应用户的推荐缓存。
6. 歌曲评论改为每页 20 条加载，2,000 条测试评论的首屏 JSON 数据量由约 318 KB 减至 3.5 KB。
